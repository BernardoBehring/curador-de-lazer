# Find local sources

Input: $ARGUMENTS (Home, or a Request location)

1. Start with the profile's "Preferred sources", if any.
2. Add, by searching the web for that city and country:
   - the city's/municipality's official cultural agenda;
   - local theatres, cinemas and libraries;
   - the country's main ticketing platforms (e.g. Portugal: BOL, Ticketline,
     Viral Agenda);
   - streaming availability for the country (e.g. JustWatch for that country);
   - the country's main bookshops.

Output: a short list of sources grouped by kind (events, streaming, books).
