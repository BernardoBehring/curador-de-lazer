# Start a session

Orchestration only — no rules here.

1. No `profile.md` → `profile-interview`, then stop (the interview ends with a round).
2. `list-pending`.
3. "check-in overdue" in the result → `check-in`.
4. "past events" in the result → ask how each went, then `log-feedback` with the answers.
5. Hand over to the skill for the user's request.
