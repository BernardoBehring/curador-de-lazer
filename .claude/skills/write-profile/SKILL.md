# Write the profile

Input: $ARGUMENTS — the confirmed Leisure Profile, or only the fields to change.

Write `profile.md` in the user's Language with this fixed structure (translate
the headings) and set "Confirmed on" to today:
```markdown
# Leisure Profile
_Confirmed on: YYYY-MM-DD_

## Context
- Language: …
- Title languages: …
- Home: city, country
- Maximum distance: …
- Free time: weekdays … · weekends …
- Email: … | off
- Preferred sources: …

## Films
- Likes: …
- Dislikes: …

## Series
- Likes: …
- Dislikes: …
- Preferred format: …

## Books
- Likes: …
- Dislikes: …
- Format · pace · reading languages: …
- Libraries: no / which

## Events
- Likes: …
- Dislikes: …
- Calm or lively: …

## Platforms
- …

## Budget
- Per event: … (currency)

## Mood
- …

## Openness
N/5

## Companions
### Name
- Relationship: …
- Strong "no"s: …
- Shared tastes: …
```
When only some fields are given, change those and keep everything else as is.
